# Contributing to Syllog

Thank you for improving Syllog. This is an experimental compiler/runtime, so
changes must preserve accurate claims and be supported by tests.

Read [`docs/contributing.md`](docs/contributing.md) before submitting a change.
It defines the pinned tools, test-first workflow, compatibility rules, and the
mandatory `bash scripts/ci.sh` gate. Language syntax, effects, capabilities,
public formats, runtime ABIs, and trust boundaries require the RFC process;
significant architectural decisions require an ADR.

Use a focused branch, avoid unrelated formatting or generated files, add a
regression test for each fixed defect, and explain security/compatibility impact
in the pull request template. By participating, you agree to follow
[`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).
