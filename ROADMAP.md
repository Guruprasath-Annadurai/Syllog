# Syllog Roadmap

Work advances through evidence gates, one layer at a time. A later layer cannot
be treated as complete because prototypes for it already exist.

1. **Repository truth:** identity, reproducible CI, architecture authority,
   governance, and honest status.
2. **Language core:** freeze and prove a coherent Syllog 0.1 subset from source
   through interpreter and Wasm, including bounded ownership/effect/async scope.
3. **Developer ecosystem:** installation, release artifacts, CLI completeness,
   formatter, LSP, editor support, and public documentation.
4. **Typed AI programming:** typed models/tools, enforced budgets and
   capabilities, provider portability, and a capability-safe reference agent.
5. **Governed cognitive systems:** bounded graphs, structured concurrency,
   typed evidence/provenance, and human approval boundaries.
6. **Reproducible experimentation:** immutable evaluations, controlled candidate
   promotion, independent approval, monitoring, and rollback.
7. **Interoperability and adoption:** Component Model/WIT, stable SDKs, secure
   registry operations, external examples, and community governance.

`evo` and `asi_loop` remain post-1.0 research topics. They require separate RFCs,
threat models, isolation, independent stop/approval control, and adversarial
evidence before implementation in a stable channel.
