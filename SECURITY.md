# Security Policy

Syllog is experimental and has no production-ready release. Do not use it as a
security boundary for sensitive workloads without an independent review.

Report suspected vulnerabilities through GitHub private vulnerability reporting
for [`Guruprasath-Annadurai/Syllog`](https://github.com/Guruprasath-Annadurai/Syllog/security/advisories/new).
Do not include exploit details, credentials, or personal data in a public issue.
The bootstrap response targets and disclosure rules are defined in
[`docs/governance/security.md`](docs/governance/security.md).

Currently supported security fixes target the latest `main` revision only;
there is no stable release series yet. Known limitations are tracked in
[`docs/feature-status.md`](docs/feature-status.md) and
[`docs/runtime-foundations.md`](docs/runtime-foundations.md).
